## 💡 为什么做这个

**47 次巨无霸、¥1,286、连续 23 天的断食**——这些数字你自己都记不清，但 AI 记得。

麦当劳官方 MCP 开放了真实的订单、积分、优惠券、活动数据。与其让这些数据躺在后台，不如把它变成一份**有仪式感的年度账单**：你今年吃了多少次、花了多少钱、最爱哪一口、断了几天，一目了然。

这个 Skill 做的事情很简单：**把你的真实订单，翻译成一份值得截图发出去的年度报告。**

> 不用你记，你只要问。

### 🏅 麦门指数分档

年度总结会给你一个专属称号：

| 指数 | 称号 | 解读 |
|:---:|---|---|
| 90-100 | 麦门至尊信徒 | 今天不吃麦当劳，功德会掉 |
| 70-89 | 麦门忠实信徒 | 虔诚度在线，稳住 |
| 50-69 | 麦门摇摆路人 | 可吃可不吃，看心情 |
| 30-49 | 麦门叛逃者 | 该回来吃吃了 |
| 0-29 | 麦门逆子 | 快去吃个汉堡赎罪 |

### 📅 个人化星期偏好

「今日宜吃指数」的星期维度不是按通用规则给分，而是**基于你自己的历史订单节奏**算出来的：

调用 `order-list` 拉取你历史订单 → 统计每个星期几的下单次数 → 算出今天的「星期偏好分」：

```
星期偏好分 = 今日所在星期的历史占比 ÷ 历史最高占比 × 100
```

**举例**：你历史订单里周五 12 单、周六 15 单（最高）、周三只有 1 单——
- 今天是周五 → 12 ÷ 15 × 100 = **80 分**（撞上你的吃麦节奏）
- 今天是周六 → 15 ÷ 15 × 100 = **100 分**（你的主战场，满分）
- 今天是周三 → 1 ÷ 15 × 100 ≈ **7 分**（不是你的吃麦日）

> 为什么这么设计：每个人吃麦当劳的节奏都不一样。有人天天周五金币套餐，有人周末才出门。比起「周六就是高分」的通用规则，让分数随你的真实节奏浮动，才能在「今天就是你平时吃的日子」时给出更有说服力的推荐。
>
> 数据不足时（历史订单 < 5 单）自动降级为通用偏好，避免样本太少导致误判。

## 🚀 快速开始

### 第 1 步：申请 MCP Token

访问 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp)：

```
手机号登录 → 控制台 → 激活 → 同意服务协议 → 复制 Token
```

### 第 2 步：配置 MCP

把 `mcp-config.example.json` 里的 `${MCD_MCP_TOKEN}` 换成你的 Token，粘贴到你的 MCP 客户端（WorkBuddy / Cursor / Cherry Studio / Claude Code 等）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}
```

> 也可以直接用环境变量注入，避免 Token 落盘：`export MCD_MCP_TOKEN=your_token_here`

### 第 3 步：加载 Skill

把 [`SKILL.md`](SKILL.md) 作为系统提示词 / Skill 文件加载到 AI 客户端，然后直接问：

- 「看看我的麦门年度总结」
- 「我今年吃了多少次麦当劳」
- 「今天宜吃麦当劳吗」

> 详细图文步骤见 [workbuddy.md](workbuddy.md)（WorkBuddy 专项）或 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。

## ⚙️ 工作原理

```
年度总结                              今日宜吃
   │                                      │
   ├─ order-list        拉历史订单        ├─ order-list        断食天数
   ├─ query-my-account  查积分余额        ├─ campaign-calendar 今日活动
   └─ query-my-coupons  查券包            └─ query-my-coupons  临期券
   │                                      │
   └─► 统计 + 麦门指数分档                └─► 加权计算 0-100 宜吃指数
   │                                                  │
   └─► 输出报告 ──────────────────────────► 确认后 → query-meals
                                                       → calculate-price
                                                       → create-order
```

**所有数字均来自麦当劳 MCP 真实返回**，不编造、不虚构。工具调用失败时自动降级使用已有数据，不中断流程。
