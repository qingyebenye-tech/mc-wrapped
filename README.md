# 麦门年度总结 🍟

> 你的 2026 麦门年度账单：今年吃了多少次麦当劳？花了多少钱？最爱哪一口？

像网易云年度听歌报告、Spotify Wrapped 一样，输入你的麦当劳订单数据，生成一份专属的麦门年度总结。

## 它能做什么？

### 🏆 年度总结
拉取你的全部麦当劳订单，告诉你：
- 今年吃了多少次、花了多少钱
- 你最爱点什么、第二名第三名是什么
- 哪个月吃得最多、星期几最常吃
- 你最长连续吃了几天、最长断食了几天
- 你手上还有多少积分、多少张券

### 🔔 麦门关怀提醒（看完报告后可选开启）
开启后，每次打开它会自动告诉你：
- 你已经多久没吃麦门了
- 今天宜不宜吃麦当劳（结合活动、券、断食天数）
- 今天宜吃什么，直接帮你下单

## 怎么用？

### 前置条件
1. 去 [麦当劳 MCP 平台](https://open.mcd.cn/mcp) 注册拿 Token
2. 在 AI 客户端配置：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}
```

> ⚠️ 替换为你自己的 Token，不要把真实 Token 提交到公开仓库。

### 开始
把 `SKILL.md` 作为系统提示词加载，然后问：

- "看看我的麦门年度总结"
- "我今年吃了多少次麦当劳"
- "今天宜吃麦当劳吗？"
