# 麦门年度总结 🍟

> 你的 2026 麦门年度账单：像网易云年度听歌报告一样，回顾你和麦当劳的一年。

拉取你的麦当劳真实订单数据，生成一份有仪式感的年度总结——今年吃了多少次、花了多少钱、最爱哪一口、断食了几天。看完报告后还能开启每日关怀提醒，告诉你今天宜不宜吃麦当劳。

## 功能特性

- 📊 **年度总结**：累计次数、总花费、最爱餐品、最频繁月份、最长连续、最长断食
- 🔔 **断食提醒**：超过 7 天没吃麦门自动警告
- 🌤️ **今日宜吃指数**：结合活动日历、临期券、断食天数算出 0-100 宜吃分
- 🍔 **一键推荐**：告诉你今天宜吃什么，直接引导下单

## 快速开始

### 1. 申请 MCP Token

打开 https://open.mcd.cn/mcp ，手机号登录 → 控制台 → 激活 → 复制 Token。

### 2. 配置 MCP

把 `mcp-config.example.json` 中的 `${MCD_MCP_TOKEN}` 换成你的 Token，粘贴到 MCP 客户端（WorkBuddy / Cursor / Cherry Studio / Claude Code 等）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}
```

### 3. 加载 Skill

把 `SKILL.md` 作为系统提示词加载到 AI 客户端，然后直接问：

- "看看我的麦门年度总结"
- "我今年吃了多少次麦当劳"
- "今天宜吃麦当劳吗"
